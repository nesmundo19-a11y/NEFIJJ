# 07. Guía de Desarrollo Backend - NEFIJJ

## 1. Introducción y Prerrequisitos
Esta guía detalla los pasos para configurar, levantar y ejecutar el servidor backend de **NEFIJJ** utilizando **Python**, **Django 5.x** y **MySQL 8.0**.

## 2. Prerrequisitos en el Equipo
* Python (versión 3.10 o superior) instalado en el sistema.
* XAMPP con el servicio de **MySQL** activo.
