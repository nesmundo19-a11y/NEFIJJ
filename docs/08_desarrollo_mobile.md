# 08. Guía de Desarrollo Mobile - NEFIJJ

## 1. Introducción y Prerrequisitos
Esta guía detalla los pasos para configurar, ejecutar y probar la aplicación móvil de **NEFIJJ** utilizando **React Native** con **Expo framework**.

## 2. Prerrequisitos en el Equipo
* **Node.js** (Versión LTS recomendada) instalado en la computadora.
* Aplicación **Expo Go** instalada en el dispositivo móvil (Android o iOS) conectada a la misma red Wi-Fi que la computadora.

## 3. Pasos de Inicialización y Ejecución

### A. Inicializar el Proyecto de Expo
Abre la terminal en la raíz del proyecto y dentro de la carpeta `mobile/` ejecuta:

cd mobile
